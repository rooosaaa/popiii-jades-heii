# Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters

This repository contains supplementary data products associated with the paper:

> *Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters*

The repository contains the resolved spectral energy distribution (SED) fitting overview plots generated using the `EXPANSE` pipeline for the He II-emitting galaxies analysed in this work.

## Contents

* `resolved_sed_fitting_overview/` — resolved SED fitting overview plots.

  * `candidates/` — resolved SED fitting overview plots for the Pop III candidate galaxies discussed in the paper.
  * `full_sample/` — resolved SED fitting overview plots for the full sample of 62 resolved He II-emitting galaxies.

The overview plots include the resolved SED fitting results, resolved maps, and associated physical-property distributions for each galaxy. The source IDs used in the filenames correspond to those adopted throughout the paper.

## Data availability

The resolved SED fitting overview plots are publicly available through this GitHub repository and are permanently archived on Zenodo.

The current release, **v1.0.0**, corresponds to the version of the supplementary data products associated with this work and is archived on Zenodo:

https://doi.org/10.5281/zenodo.21863065

The Zenodo record provides a persistent archive of the `v1.0.0` GitHub release. Subsequent updates to the supplementary data products will be assigned new version numbers and archived as separate Zenodo releases.
