# Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters

This repository contains supplementary data products associated with the paper:

> *Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters*

The repository contains the resolved spectral energy distribution (SED) fitting overview plots generated using the `EXPANSE` pipeline for the He II-emitting galaxies analysed in this work.

## Contents

* `resolved_sed_fitting_overview/` — resolved SED fitting overview plots.

  * `candidates/` — resolved SED fitting overview plots for the Pop III candidate galaxies discussed in the paper.
  * `full_sample/` — resolved SED fitting overview plots for the full sample of 62 resolved He II-emitting galaxies.

The overview plots include the resolved SED fitting results, resolved maps, and associated physical-property distributions for each galaxy. Source IDs used in the filenames correspond to those adopted throughout the paper.

## Data availability

A versioned release of these supplementary data products is permanently archived on Zenodo:

https://doi.org/10.5281/zenodo.21863065

The GitHub repository provides convenient access to the individual figures, while the Zenodo record provides a persistent archive of the released data products.
