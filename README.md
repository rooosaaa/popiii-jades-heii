# Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters

This repository contains supplementary data products associated with the paper:

> Sown at Cosmic Dawn: Searching for Pop III Signatures in JWST JADES He II Selected Line Emitters

The repository contains the broadband spectral energy distribution (SED)
overview plots for the galaxies analysed in the study.

## Contents

- `sed_overview/` — SED overview plots for individual galaxies.

The source IDs used in the filenames correspond to those adopted throughout
the paper.
